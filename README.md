# SIMULATOR

Система найма и обучения стажёров отдела продаж.

## Что здесь

| Путь | Что это |
|---|---|
| `docs/index.html` | **Коробка стажёра** — операционный набор для РОПа: воронка найма, пять гейтов, маршрут лидов, правила отсева |

## Статус

Этап 0 — операционная часть. Работает без софта:

- [ ] Тиры лидов A/B/C в amoCRM (права доступа)
- [ ] Рубрика 6 навыков, согласованная с РОПом
- [ ] Наставники + бонус за выведение
- [ ] Мотивация РОПа: план + стажёры + цена лида

Этап 1 — дашборд поверх существующей системы речевой аналитики.

Этап 2 — голосовой тренажёр отработки возражений (OpenAI Realtime).
Нужен не раньше, чем выдохнется мёртвая база и заработает рубрика.
